# Hi, I'm Haradas 👋

Master's student in cybersecurity, in a work-study program, learning to build systems that are useful **and** hard to
break. I like understanding how things work end to end, from the network edge to the last log line.

## 🔐 What I focus on

- **System hardening**: least-privilege services, sandboxed daemons, secrets kept out of code
- **Network security**: reverse proxy access control, TLS, exposing only what's needed
- **Monitoring & incident analysis**: reading logs, tracing root causes, fixing them for good
- **Automation**: turning repetitive ops work into tested, reliable code
- **Backup & resilience**: consistent backups, rollback plans, services that recover on their own

## 🛠️ Tools I work with

- **Systems**: Linux, systemd, Docker / Docker Compose
- **Languages**: Rust, Python, Bash, JavaScript
- **Network & web**: Nginx, reverse proxies, VPN, DNS
- **Observability**: Grafana, InfluxDB, Telegraf
- **Workflow**: Git, CI checks, documented runbooks
